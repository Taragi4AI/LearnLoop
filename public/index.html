About this playground

A single app that exercises every Boson AI (Higgs) developer API. The browser never holds your API key — all calls go through the local Express proxy in server.js, which attaches the Authorization: Bearer header. For Realtime, the server mints a short-lived client secret and the browser connects directly over WebSocket.
